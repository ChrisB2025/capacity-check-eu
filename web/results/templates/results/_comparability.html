Named limit: one shock, 27 different countries

Every member state gets the same shock: {{ p.shock_pct|floatformat }}% of its GDP, with the same spending mix. But countries differ in climate, building stock, tenure (Finland's well-insulated cooperative flats are not Sweden's detached houses), incomes and habits. The renovation work a uniform shock implies may therefore be badly out of line with what any one country would actually do. This limits what the results can claim; it is not a passing caveat.

You can compare

  • Where the same financial shock presses hardest, relative to each industry's workforce and its own shortage history.
  • Which industries come up as tight or binding in many member states, and which in few.
  • How much of each programme's work is done outside the spending country.

You cannot compare

  • What each country would need to spend, or how many homes it would need to renovate.
  • Whether one country's renovation programme is more feasible than another's.
  • The size of any country's real renovation need.

The uniform shock is deliberate. It makes the variation between countries visible and gives each a common starting point. The method is built to be rerun by any country with its own spending mix and data.
