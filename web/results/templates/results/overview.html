How it works

Spending is a claim on real resources: people, materials, energy. This asks a different question from the usual one. Not how to pay for a programme, but whether the people are there to do the work, and where they would run short. Five steps, using the figures from the base run.

  1. 1

    Spend the money

    €{{ ov.shock_meur|bn }}bn: {{ ov.shock_pct|floatformat }}% of {{ ov.gdp_year }} GDP in each of the {{ ov.countries }} member states, spent in one year on housing and energy renovation. Every country gets the same share of its GDP, so the same financial push, not the same physical programme.

  2. 2

    Follow it through supply chains

    Builders buy materials, materials makers buy energy and metals, and so on down the chain. Eurostat's FIGARO tables trace every round across 64 industries in every EU country and its trading partners. In all, the programme needs €{{ ov.required_output_meur|bn }}bn of output, made here:

    • in the spending country {{ ov.required_home_share|pct }}
    • elsewhere in the EU {{ ov.required_rest_eu_share|pct }}
    • outside the EU {{ ov.required_non_eu_share|pct }}
  3. 3

    Count the people it needs

    Each industry's output per worker turns that into people: {{ ov.extra_persons_eu|millions }} million more in work across the EU for a year.

    Example: {{ ov.example_industry_label|lower }} in {{ example_name }}

    {{ ov.example_industry_label }} in {{ example_name }} would need {{ ov.example_extra_persons|hundreds }} more people, on top of the {{ ov.example_employment|millions:2 }} million it employs now. That is {{ ov.example_pressure|pct:1 }} more.

  4. 4

    Ask firms whether they can find them

    The European Commission asks firms in every member state what is holding back their activity. One answer is "shortage of labour". Each industry's current reading is placed against its own history, so a country where firms always complain is not mistaken for one in sudden trouble.

    Rate each industry, then add up

    Each of the 64 industries in each country gets one of four ratings, combining the extra people needed (step 3) with what firms report (step 4).

What it does not tell you

It shows where a programme would press on workers. It does not forecast prices, say whether a programme is affordable, or see limits in permits, grid connections or training places. The results also depend on which shortage measure is used, a question now with the reviewer. The full list is at the foot of every page.
